# JetPunk Quiz Helper: US States by Borders (90 Seconds)

A minimalist HTML application featuring a side-by-side view designed to help you beat the extremely difficult (and normally almost impossible) JetPunk quiz: *“US States by Borders in 90 Seconds”*.

The app lists all the required states in a perfectly sorted layout, allowing you to quickly copy and paste them directly into JetPunk while the timer is running.

## Features

- **Side-by-Side Optimized:** The layout is built exceptionally slim so it fits perfectly on one half of your screen while the quiz runs on the other.
- **Copy-Optimized:** Fast access to all state names without unnecessary scrolling or searching.
- **Zero Dependencies:** Pure, lightweight HTML file. Runs completely locally in your browser without any server or internet connection required.

## How to Use

1. Download the HTML file from this repository (or clone the repo).
2. Open the file with a double-click in any web browser (Chrome, Firefox, Safari, Edge).
3. Place the helper window on one half of your screen and the JetPunk quiz on the other.
4. Start the quiz and use the list for ultra-fast copying and pasting.
